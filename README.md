# NightThreadShop — one-page storefront

Plain HTML/CSS/JS, no build step. Open `index.html` via any static server:

    cd nightthread-site && python3 -m http.server 8088

- `index.html` – markup and copy
- `styles.css` – all styling (dark/neon theme, responsive, reduced-motion support)
- `main.js` – reveal-on-scroll, hero parallax + neon rain canvas, front/back card toggle, copy-code, mobile menu, reels autoplay when visible
- `assets/img` – product cut-outs (from Printful AOP mockups), art close-ups (from the Printful print panels), favicon
- `assets/video` – compressed, muted 480p versions of three TikTok promo reels
- `assets/fonts` – self-hosted Latin subsets of Unbounded, Space Grotesk, JetBrains Mono (Google Fonts, SIL Open Font License)

All purchases happen on Etsy (links open in a new tab). Discount code: NIGHT10 (10% off).
Technology specs are taken from Printful's catalog description of the All-Over Print Recycled Unisex Hoodie (product 388).
